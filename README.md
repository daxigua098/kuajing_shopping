# FenFlow · 跨境开店业务分发与代理分账平台

基于《项目设计说明书》和《技术参数说明》实现的可运行前端 MVP。当前版本使用 Vue 3 + TypeScript + Vite，业务数据保存在浏览器 localStorage 中，重点验证多角色数据权限、代理树、店铺/人头档案、杂费报销和月度分账链路。

## 已实现功能

- 四角色演示登录：平台管理员、公司负责人、顶级代理、子代理
- 角色级导航、按钮权限和业务数据范围隔离
- 经营工作台：店铺健康、应结金额、待办、趋势和代理收益
- 公司管理：新增、编辑、停用、统计和 CSV 导出
- 代理体系：多级代理树、直属代理标识、公司关联；按店铺类型统计开店总点、有效提交人头、存活店、挂店/死店和未开店人数
- 人头档案：顶级代理和代理均可录入；支持整段文本智能粘贴识别姓名、IC、邮箱、电话、银行账号、银行卡号、CVV 和有效期
- 人头图片：支持身份证正反面、银行卡正反面、开店/关店截图和文字备注
- 店铺档案：公司、代理、人头、IC 卡号、银行卡号、类型、租金模式、开/关店状态和图片凭证查看
- 人头提交工作台：顶级代理和子代理都可直接添加人头；子代理先提交给顶级代理，顶级代理再分配公司；支持按已开店、挂店、未开店、待审核和店铺类型筛选
- 人头业务状态：未开店、已开店、死店、无效人头；公司只能为已审核通过且类型匹配的人头开店
- 开店任务：公司发布、代理承接、进度更新和完成判定
- 分配规则：公司/代理/店铺类型规则、版本号、有效期和砍头/按月模式
- 垫付杂费：录入、凭证、按状态/月份筛选、公司确认或驳回、全额报销
- 月度核算：店铺存活判定、砍头首月判断、店租 + 杂费合并、批次确认
- 支付与对账：应结、实结、差异、支付时间线和财务留痕
- 报表导出：店铺、人头、核算、杂费和代理维度，支持 CSV/TXT 参数
- 系统设置：四套 UI 主题、语言偏好、数据备份和演示数据重置
- 操作日志：登录、档案修改、规则、核算、支付和导出留痕

## 本地运行

```bash
pnpm install
pnpm dev
```

浏览器打开 `http://localhost:5173`，点击角色卡片即可进入演示。

生产构建：

```bash
pnpm build
pnpm preview
```

## 核心结算规则

- 每月 10 日核算上月。
- 上月任意一天存活即按整月结算。
- 关店后从次月停止按月结算。
- 砍头模式只在开店首月支付。
- 店租按公司/代理/店铺类型规则逐级分配。
- 杂费由顶级代理垫付，公司全额报销，不逐级分配。
- 公司应付为店租与垫付杂费之和。
- 已确认批次锁定，正式环境修正必须走调整单、冲正单或重新生成批次。

## 当前实现边界

这是用于确认 UI 与业务流程的前端 MVP，不包含真实后端、数据库、对象存储、短信/邮件、定时任务和生产级安全。正式开发应按技术文档接入：

```text
Spring Boot 3 + Java 21 + MySQL 8 + Redis + 对象存储 + Nginx + Docker
```

前端数据接口集中在 `src/store.ts`，后续可将 store actions 替换为 REST API，不影响主要页面结构。

### 子代理端权限

子代理只显示：经营工作台、人头档案、人头提交、只读店铺档案、系统设置。

- 可添加、编辑自己代理树下的人头
- 可选择店铺类型并提交给顶级代理分配公司
- 可查看未开店、已开店、挂店和人头资料
- 不显示开店任务、杂费、月度核算、支付对账和报表模块
- 不能承接开店任务或选择公司

### 人头导出默认字段

默认导出：人头姓名、IC 卡号、银行卡、店铺。

可选字段：联系电话、邮箱、业务状态、归属代理、提交公司、店铺类型、开户银行、银行账号、CVV、有效期、图片数量、备注。

### 垫付杂费凭证

杂费凭证只接受图片截图上传，支持列表缩略图、详情大图预览；公司端可以上传或替换待确认杂费的凭证截图。

### 公司月度核算视图

公司端可在店租和杂费之间切换。店租只展示上月存活店铺和新开店铺前 3 个月保护期的应付店租；不展示人头、代理分配及核算说明。

公司店租明细显示开店日期、关店日期和存活周期；汇总报表显示平均存活周期。

公司结算模式按 companyId 隔离：每家公司只能设置和查看自己的店铺结算模式、一次性金额或按月金额，不会读取其他公司的配置。

### 公司结算模式分类

公司先在“结算模式”页面创建自己的一次性或按月结算分类。公司审核人头通过后，在开店弹窗中选择结算模式分类，系统将模式和金额快照到店铺。分类按 companyId 隔离，不同公司互不影响。

### 公司店铺类型管理

公司可新增、编辑、删除自己的运营平台，例如 TikTok Shop、Shopee、Amazon。若类型下仍有存活店铺，数据层会阻止删除。新增店铺时只展示当前公司生效的店铺类型。
